DESIGN DIRECTION — HYBRID 3D INTERACTIVE

Create a premium Hybrid Digital Agency experience combining Dark Luxury, immersive 3D Interactive elements, and sophisticated SaaS dashboard aesthetics.

Use a deep black background, refined purple and electric blue accents, premium typography, floating interface elements, and carefully designed 3D objects.

The Hero section must feature a distinctive interactive 3D centerpiece using Three.js and React Three Fiber.

Integrate:

Interactive 3D hero experience.

Floating 3D dashboard components.

Mouse-responsive visual effects.

Smooth scroll-based animations.

GSAP cinematic transitions.

Framer Motion micro-interactions.

Premium project presentation.

Interactive service experiences.

TECHNICAL STYLING RULE:
Use Tailwind CSS as the primary and exclusive styling system. Do not create separate CSS or SCSS files. Use reusable Tailwind components and maintain a consistent design system.

Prioritize premium aesthetics, usability, accessibility, responsiveness, and GPU performance.
